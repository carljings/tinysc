## 状态含义

- **通过**：本页要求的证据已经实际取得。
- **有条件通过 / 证据不完整**：已列功能结果成立，但指定的汇总或阈值证据没有完整保存；必须同时
  披露限制，不能缩写成无条件通过。
- **未通过**：已经执行但没有达到门槛，或发布门禁仍有必要项目缺失。

## 真实应用边界

- Legacy WAR B 的 `183,945 ms` 是从启动到外部 HTTP 就绪；其中 Spring MVC 初始化记录为
  `141,923 ms`，启动链同时出现业务数据库序列错误。该冷启动由业务和数据库主导，不能归因于
  tinysc 容器本身。
- B 的热态业务 `page_load` 约 `1.36–3.03 s`，两个 `.tpl` 约 `6 ms`。代表性静态对象首次
  返回 `200`、`51,104` 字节、`23.751 ms`，随后条件请求返回 `304`、`0` 字节、`19.239 ms`。
- Legacy WAR A 仍受外部数据库阻塞，状态为**受阻**。A 不阻断只针对 B 的已授权切换事实，但它
  阻断“两份真实 WAR 均通过”和 1.0 的广泛兼容结论。
